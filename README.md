## 🛠️ How to Use

### Option 1: Local Development
1. Download all files to your computer
2. Open `index.html` in your web browser
3. Navigate through different sections using the navigation menu

### Option 2: Deploy to GitHub Pages
1. Create a new GitHub repository
2. Upload the `index.html` file to the repository
3. Go to repository Settings > Pages
4. Select "Deploy from a branch" > main branch
5. Your site will be available at: `https://yourusername.github.io/repository-name`

### Option 3: Deploy to Netlify
1. Go to [netlify.com](https://netlify.com)
2. Sign up/login to your account
3. Drag and drop the `index.html` file
4. Your site will be live instantly with a free custom URL

### Option 4: Deploy to Vercel
1. Go to [vercel.com](https://vercel.com)
2. Sign up/login to your account
3. Import the project or drag and drop files
4. Get a free custom domain for your portfolio

## 📝 Customization Guide

### Updating Personal Information
1. **Name and Title**: Edit line 6 and line 12 in `index.html`
2. **Contact Information**: Update lines 156-167 (Contact section)
3. **About Section**: Modify lines 104-128
4. **Skills**: Edit lines 164-216 to add/remove technologies
5. **Projects**: Update lines 218-290 with your actual projects

### Adding Your Photo
Replace the placeholder profile image (line 113) with your actual photo:
```html
<!-- Replace this: -->
<div class="profile-image">
    <i class="fas fa-user"></i>
</div>

<!-- With this: -->
<img src="your-photo.jpg" alt="Your Name" class="profile-image">
```

### Customizing Colors
The main brand color is `#667eea` (purple-blue). To change it:
1. Search for `#667eea` in the CSS
2. Replace with your preferred color
3. Also update `#764ba2` (the gradient end color)

### Adding More Projects
1. Find the `.projects-grid` section
2. Copy an existing `.project-card` block
3. Update the content with your new project details
4. Add new technology tags as needed
